# DEPLOYMENT

## Текущая локальная версия
Требования: Rust stable и Cargo.

```sh
cargo run --release
```

Открыть `http://127.0.0.1:8080`.

Тесты:
```sh
cargo test
```

## Переменные текущего сервера
- `CHAT_ADDR`: адрес bind; если не задан, используется `PORT` или `127.0.0.1:8080`.
- `PORT`: порт хостинга.
- `CHAT_PROXY_HOPS`: число доверенных прокси, по умолчанию 0 в коде; Render config задаёт 1.

## Docker / Render
В репозитории есть Dockerfile и render.yaml. Наличие конфигурации не является подтверждением успешного актуального деплоя.

## План следующего этапа
После подключения PostgreSQL обновить инструкции переменными подключения, миграциями, backup/restore и health checks. Секреты хранить в секретах хостинга, не в git.
