# SECURITY

## Текущее состояние
- Есть проверка Origin для WebSocket, ограничение размера кадров, лимиты подключений, лимит сессий с IP и rate limit сообщений.
- Ограничения, сессии, жалобы и баны хранятся в памяти и сбрасываются при перезапуске.
- Возраст и пол вводятся пользователем; достоверной проверки возраста нет.
- В текущем коммите взрослые категории удалены из интерфейса, а серверный парсер принимает только тему `chat`. Это не является проверкой возраста и не подтверждает безопасность публичного запуска.

## Обязательные меры до публичного запуска
1. Реализовать возрастную модель, соответствующую аудитории и юрисдикциям; не раскрывать точные возрастные данные другим пользователям.
3. Защитить несовершеннолетних от контактов со взрослыми, grooming, преследования и вымогательства; тестировать серверные правила.
4. Добавить блокировки, жалобы и процесс рассмотрения с минимально необходимым контекстом.
5. Перейти на поддерживаемые HTTP/WebSocket библиотеки и провести security review.
6. Добавить Argon2id, rate limits на регистрацию/вход, CSRF-защиту где применимо, безопасные cookies, ротацию и отзыв сессий.
7. Проверять права на каждом приватном API и WebSocket событии.
8. Проверять реальные MIME/сигнатуры и лимиты медиа до их включения.
9. Не логировать пароли, токены, личные сообщения и лишние персональные данные.
10. Провести тестирование уязвимостей и проверку политик хранения/удаления.

Не считать сервис безопасным для открытого доступа до выполнения и проверки этих требований. TLS должен обеспечиваться на публичном ingress.
