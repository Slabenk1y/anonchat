# Эхо — анонимный чат на Rust

Чистый Rust без внешних зависимостей. Все файлы лежат в корне, папок нет.

- `main.rs` — HTTP и WebSocket-сервер, пульс, проверка Origin
- `ws.rs` — WebSocket (SHA-1, base64, кадры) на чистом std
- `state.rs` — подбор пары, фильтры, лимиты, жалобы и баны
- `index.html` — меню и чат

Локально: `cargo run --release`, затем http://127.0.0.1:8080. Тесты: `cargo test`.

Переменные: `CHAT_ADDR`, `PORT` (на хостингах), `CHAT_PROXY_HOPS=1` (число прокси перед сервером; без него все пользователи выглядят как один IP).

## Как работает

Чат идёт по WebSocket (`/ws`). Закрытие вкладки видно сразу. Клиент шлёт `ping` каждые 15 с, сервер шлёт пульс; тишина дольше 45 с закрывает сессию. В пару берутся только «живые» ожидающие.

Три темы: Общение, Флирт (18+), Ролка (18+). Подбор взаимный: тема, пол и возраст должны устраивать обе стороны.

Правило безопасности: пользователи «до 17 лет» соединяются только друг с другом, взрослые их никогда не получают. Во Флирте и Ролке «до 17» недоступно. Возраст и пол указываются самими пользователями и не проверяются.

## Ограничения

Возраст не проверяется. Нет автомодерации текста. Бан по IP грубый. Всё в памяти: после перезапуска сессии и баны пропадают. Нет HTTPS на уровне сервера (его даёт хостинг).
