# Эхо — анонимный чат

Текущий проект — ранняя версия международной платформы случайного общения. Backend написан на Rust 2021, сборка через Cargo и Docker.

## Что уже есть
- HTTP-сервер и health check.
- WebSocket-соединения.
- Подбор случайного собеседника с взаимными фильтрами.
- Текстовые сообщения и индикатор набора.
- Heartbeat, завершение диалога, базовые лимиты и жалобы.
- Адаптивный веб-интерфейс с настройками и 10 темами оформления.

## Честные ограничения текущей версии
- Нет регистрации и авторизации.
- Нет PostgreSQL: активные сессии, очередь, жалобы и баны хранятся в памяти и теряются при перезапуске.
- Возраст не проверяется; пользователь сам выбирает категорию. Подростковая категория в интерфейсе обозначена как `13–17 лет`; возраст не проверяется, поэтому это самодекларируемый фильтр, а не подтверждение возраста.
- Нет постоянной истории сообщений, загрузки медиа, платежей или магазина.
- Взрослые категории отключены в интерфейсе и серверной валидации. Возраст при этом всё ещё не проверяется, поэтому публичный запуск требует дальнейшей работы по возрастной безопасности.
- Наличие тестов в исходниках не означает, что они прошли в текущем окружении.

## Локальный запуск
Нужен Rust stable:

```sh
cargo run --release
```

Откройте http://127.0.0.1:8080.

Запуск тестов:

```sh
cargo test
```

## Конфигурация
- `CHAT_ADDR` — адрес сервера.
- `PORT` — порт хостинга, если `CHAT_ADDR` не задан.
- `CHAT_PROXY_HOPS` — число доверенных прокси; настройка должна соответствовать реальной схеме проксирования.
