# anon-chat — анонимный текстовый чат на Rust

Чистый Rust без внешних зависимостей. Все файлы лежат в корне, папок нет.

Локально: `cargo run --release`, затем http://127.0.0.1:8080. Тесты: `cargo test`.

Переменные: `CHAT_ADDR` (адрес), `PORT` (порт на хостингах), `CHAT_PROXY_HOPS=1` (число прокси перед сервером, нужно на хостинге, иначе все пользователи выглядят как один IP).

Публикация на Render: загрузить файлы в репозиторий GitHub, на render.com выбрать New → Blueprint и указать репозиторий. Бесплатный план засыпает без трафика, первое открытие после паузы занимает около минуты.

Ограничения: возраст проверяется только галочкой, бан по IP грубый, нет автомодерации, всё хранится в памяти.
