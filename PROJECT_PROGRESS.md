# PROJECT_PROGRESS — Эхо

Последнее обновление: 2026-11-07

## Текущее состояние (проверено по main)

### Реализовано в существующем коде
- Rust HTTP-сервер без внешних crate; отдаёт `index.html`, `/healthz`, `/api/online`.
- WebSocket endpoint `/ws`, собственная реализация handshake и кадров в `ws.rs`.
- Подбор пары в памяти: взаимные фильтры темы, пола и возрастной категории.
- Отмена/завершение диалога, текстовые сообщения, typing, heartbeat.
- Ограничение длины и частоты сообщений.
- Жалобы и временная блокировка по IP в памяти.
- Проверка Origin для WebSocket (разрешены только схемы HTTP/HTTPS), лимит соединений и сессий с одного IP.
- HTTP-парсер ограничивает число и размер заголовков, требует HTTP/1.1 и Host, отклоняет дубли заголовков, некорректные строки и absolute-form request-target.
- Добавлены регрессионные тесты парсера HTTP и формирования security headers.
- WebSocket проверяет коды закрытия и UTF-8 в close reason; writer отклоняет неизвестные opcode, некорректные текстовые/close-кадры и слишком длинные управляющие кадры. Добавлены тесты этих случаев.
- Браузерные security headers: запрет встраивания во frame, COOP/CORP, CSP с `frame-ancestors 'none'`, запрет ненужных разрешений камеры/микрофона/геолокации.
- Клиентский интерфейс с адаптивной вёрсткой, настройками и 10 локальными темами.

### Подготовлено, но ещё не подключено
- Добавлена первая PostgreSQL-миграция `migrations/0001_accounts_and_safety.sql`: пользователи, хеши сессий, профили, настройки, блокировки, жалобы и история модерации. Миграция не применялась, сервер пока не использует PostgreSQL.

### Не реализовано (не считать готовым)
- Регистрация, вход, гостевые аккаунты и восстановление доступа.
- Постоянная база данных и миграции.
- Сохранение аккаунтов, настроек, покупок или истории.
- Надёжная очередь исходящих сообщений и статусы доставки/прочтения.
- Реальная загрузка медиа и голосовые сообщения.
- Перевод, уведомления и push.
- Серверные магазин, токены, подписки и платежи.
- Полноценная панель модерации, автоматическая модерация и проверка возраста.
- Нагрузочные тесты, метрики и полноценный CI.

## Подтверждённые ограничения и риски
- Все сессии, очереди, жалобы и баны живут только в памяти процесса.
- Возраст и пол в текущем подборе задаются самими пользователями и не проверяются.
- В текущей версии взрослые пространства удалены из UI и запрещены серверной валидацией. Это снижает один риск, но само по себе не подтверждает возраст пользователей и не делает сервис готовым к публичному запуску.
- Сервер использует самописный HTTP/WebSocket слой. Перед добавлением авторизации и постоянного хранилища нужно оценить переход на поддерживаемые Rust-библиотеки.
- Тесты присутствуют в исходниках, но в этой проверке они не запускались. Не считать их пройденными.

## Стек и направление
- Подтверждено: существующий проект — Rust 2021, Cargo, Docker, Render.
- Предварительное решение: сохранить Rust; перейти к модульному асинхронному backend на Tokio/Axum, PostgreSQL через SQLx, миграции; Redis оставить отложенным до появления измеримой необходимости.
- Подробности и причины — в `TECH_STACK.md` и `ARCHITECTURE.md`.

## Как запустить текущую версию
Требуется Rust toolchain:
```sh
cargo run --release
```
Открыть `http://127.0.0.1:8080`. Тесты (ещё не запускались в рамках этого аудита):
```sh
cargo test
```
