# Changelog

## [Unreleased]
- Ужесточён разбор WebSocket close-кадров: проверяются допустимые коды и UTF-8 причины закрытия; отправитель отклоняет неподдерживаемые opcode и управляющие кадры длиннее 125 байт.
- HTTP-парсер теперь ограничивает заголовки и отклоняет дубликаты/некорректный HTTP/1.1; проверка WebSocket Origin допускает только HTTP/HTTPS.
- Добавлена начальная SQL-миграция PostgreSQL для аккаунтов и базовых функций безопасности; она пока не подключена к runtime и не применялась.
- Усилены HTTP-заголовки браузерной безопасности: запрет встраивания страницы во frame, COOP/CORP, отключены ненужные браузерные разрешения камеры/микрофона/геолокации; CSP дополнена ограничениями источника и объектов.


## 2026-11-07 — безопасность первого этапа
- Удалены взрослые темы из публичного UI.
- Серверный парсер поиска теперь принимает только тему `chat`; добавлены unit-тесты на отклонение отключённых тем.
- Добавлен GitHub Actions workflow для запуска Rust-тестов на push и pull request.

## 2026-11-07 — аудит и документация
- Проверено текущее содержимое основных файлов Rust-проекта и конфигурации Render.
- Зафиксированы реально существующие возможности и ограничения.
- Добавлены файлы архитектуры, стека, проектной схемы БД, API, безопасности, деплоя и прогресса.
- Никакие новые backend-возможности не объявляются реализованными этим изменением.

## 2026-11-07
- Исправлена подростковая возрастная категория: теперь она обозначена как 13–17 лет и имеет отдельный ключ `teen_13_17` в клиенте и сервере.
- Сохранено серверное правило: категория 13–17 лет не подбирается с категориями 18+.
- Возраст остаётся самодекларируемым; проверка возраста не реализована.
