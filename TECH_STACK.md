# TECH_STACK

## Текущее состояние
- Rust 2021 / Cargo.
- HTTP и WebSocket реализованы вручную на стандартной библиотеке.
- Docker multi-stage build.
- Render как текущая площадка размещения.

## Выбранное направление (предварительное)
Сохранить Rust, не делать необоснованный переход на Node/Next.js.

Целевой стек модульного монолита:
- Backend/runtime: Rust stable + Tokio.
- HTTP/API и WebSocket: Axum.
- Сериализация и валидация: Serde + валидаторы на границах API.
- База данных: PostgreSQL + SQLx и SQL-миграции.
- Пароли: Argon2id с параметрами, подобранными и проверенными на целевом хостинге.
- Сессии: случайные непрозрачные токены; хранить на сервере только хеш токена.
- Логи: структурированные tracing-логи без секретов и содержимого личных сообщений.
- Тесты: unit + integration; отдельные проверки WebSocket и безопасности.
- Frontend: пока сохранить существующий адаптивный HTML/CSS/JS, выделяя код постепенно; не ломать текущий интерфейс ради немедленной миграции на React.

## Отложено
- Redis: только когда понадобится несколько экземпляров, распределённые очереди или измеримое кэширование.
- Объектное хранилище: до этапа медиа.
- WebRTC/TURN/SFU: до отдельного анализа безопасности и стоимости.
- Платежи и рекламные SDK: до проверки правовых и возрастных требований.

Любая новая зависимость должна иметь понятную причину, поддерживаемую версию и тесты. Секреты задаются только через переменные окружения/секреты хостинга.
